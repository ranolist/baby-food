# 집밥수첩 — 우리집 아기 먹거리·장보기 웹앱

25개월 아기를 키우는 엄마가 만든, 하루 먹거리를 정하고 장보기까지 한 번에 끝내는 모바일 웹앱입니다.

- **메뉴 추천**: 월령에 맞는 유아식 메뉴 추천
- **장보기 목록**: 필요한 재료를 한 번에 정리, 카톡용으로 복사해서 장보기
- **우리집**: 집에 있는 재료를 냉장·냉동·실온으로 나눠 재고 확인
- **레시피**: 간단한 조리 순서와 아기 반응 기록
